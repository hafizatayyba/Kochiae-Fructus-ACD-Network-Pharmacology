## Network Pharmacology and Molecular Docking Analysis of Kochiae Fructus against Allergic Contact Dermatitis
## Overview
This final year project investigates the therapeutic potential of Kochiae Fructus against Allergic Contact Dermatitis (ACD) using network pharmacology and molecular docking approaches.
## Tools/Databses Used
- TCMSP
- GeneCards
- SwissTargetPrediction
- STRING
- Cytoscape
- DAVID
- UCSF Chimera
- PyRx
- ShinnyGo
## Key Findings
- 211 common targets were identified.
- MAPK1, MAPK3, AKT1, STAT3, TP53, BCL2, BCL2L1, PIK3CB, JUN and CASP3 were identified as major hub genes.
- Oleanolic acid showed strong binding affinity with multiple target proteins.
